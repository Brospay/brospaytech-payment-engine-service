⚡ Payment Engine Service

Core Transaction Processing with TSP Integration & Smart Routing

v1.0.0

🎯 Overview

The Payment Engine is the core microservice handling all payment processing, TSP integrations, smart routing, and fraud detection.

🛠️ Tech Stack

  • Node.js 18+ / NestJS 11
  • PostgreSQL + TypeORM
  • Redis + Kafka
  • gRPC + REST + WebSocket

🚀 Quick Start

# Install dependencies
npm install

# Configure environment
cp .env.example .env

# Run database migrations
npm run migration:run

# Start development server
npm run start:dev

⚙️ Environment Variables

Variable Description Default
PORT HTTP server port 5001
GRPC_PORT gRPC server port 50001
DATABASE_HOST PostgreSQL host localhost
DATABASE_PORT PostgreSQL port 5432
DATABASE_NAME Database name valorapays_engine
REDIS_HOST Redis host localhost
KAFKA_BROKERS Kafka brokers localhost:9092
